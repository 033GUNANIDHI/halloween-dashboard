# halloween-dashboard

This Tableau dashboard analyzes Halloween event participation and visitor trends from 2008 to 2014.
It compares visitor numbers across years to show how attendance changed over time.
The dashboard also visualizes participation at different event times.
A visitor strength chart highlights the years with higher and lower attendance.
A forecast chart explores possible trends for future events.
Together, these views make the event data easier to understand and compare.
